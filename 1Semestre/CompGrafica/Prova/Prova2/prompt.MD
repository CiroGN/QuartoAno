# Prompts para IA Gemini
## Prompt 1:
```
Faça um jogo usando OpenGL e glfw para modelagem 3D, sem pygame. O jogo se chama Piramides Malditas, e é composto por formas geométricas, sendo a mior parte piramides e um cubo(jogador). A ideia do jogo é o jogador percorrer um percurso (rua) de forma triangular, o jogavor vai percorrendo ela indefinidamente (sem fim) até perder as vidas, perde-se vidas quando o jogador colide com piramides que vem em direcao contraria a do jogador com posições horizontais aleatorias. O jogador so pode se movimentar horizontalmente pelas teclas para se esquivar das piramides sem sair do caminho. As piramides (obsataculos) vem do final da rua (ponta do triangulo cima para baixo) e conforme se aproximam, seu tamanho aumenta dando sensacao de proximidade. Todos esses parametros podem se aproximar com a ideia do jogo tunnel rush. Onde o jogador percorre um caminho enquanto desvia dos obstaculos
```
